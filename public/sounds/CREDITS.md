## Синтезировано для проекта

Отрендерены скриптом на чистой математике, сторонних записей не содержат — права наши.
Формат: 16 бит, моно, 44.1 кГц, wav.

`bomb-beep`, `bomb-planted`, `bomb-plant-loop`, `defuse-loop`, `bomb-defused`, `round-start`, `round-win`, `round-lose`, `ten-second`, `flash-ring`, `bullet-whiz`, `heartbeat-loop`, `meme-pump-it`, `meme-rug-pull`, `meme-moon-launch`, `meme-airdrop`

## Как добавить или заменить звук

Положить файл в `public/sounds/sfx/` с именем ключа и выполнить `npm run sound:manifest`.
Поддерживаются ogg, flac, mp3, wav; при совпадении имён приоритет у ogg.
Файл перекрывает одноимённый процедурный звук из `src/features/game/core/proceduralSfx.ts`.
